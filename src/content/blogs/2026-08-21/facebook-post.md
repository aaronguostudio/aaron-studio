# Facebook Post (draft — personal-network tone)

I've written most of my blog with cloud models, which meant every piece of work arrived with an invoice I couldn't quite map back to the work it bought.

So I tried something: I produced this whole post — research, both languages, the images — on a 27B model running on my own laptop, through an open-source harness. No meter at all.

The short version: the local model misses things, same as before. But the gates around it caught those misses, and the log of the whole session is now the only receipt — readable by me, not by a vendor's back office.

There's a three-question test at the end for which work is worth moving local and which is not. Genuinely useful if you're getting squeezed by token bills.

What would you try first if your token meter went away?

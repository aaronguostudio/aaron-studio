# 论证备忘录

## 核心论点

Authority 不等于 capability。民主授权能给谈判者正当性，却不能自动提供一个可承受、可信的退出选项。

## 为什么现在值得写

当组织把权限交给 AI 或人时，常把“允许”误当成“能够安全完成”。

## 机制解释

公投文字范围有限；银行流动性、融资与制度关系压缩了可行选择。正当性与 leverage 同时存在，却不是同一资源。

## 证据地图

官方问题和 61.31% → ELA/bank holiday 背景 → July 新框架 → September 选举 → delegation model。

## 需要承认的反方观点

若约束总能覆盖投票，民主就会被架空。

## 对反方的回应

投票并非无意义：它决定政治授权、谈判姿态、领导更替和是否需要重获选民信任；但它不能抹去现实选项集。

## 可复用框架

**Mandate → permission → capability → constraint → accountability。**

## 对读者的启发

在给 agent 一项敏感任务前，不只问“它被允许吗”，还问“它真实具备什么能力、什么约束会中止它、事后谁负责”。

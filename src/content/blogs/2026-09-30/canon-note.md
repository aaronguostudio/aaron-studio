# Canon Note

## Canonical Idea

Legitimacy grants a mandate; it does not manufacture capability. A decision system must make both visible, then preserve accountability for the gap.

## Reusable Frame

For any consequential action, separate permission, mandate, capability, constraint, and accountability before granting execution authority.

## Claims Added

- The 2015 referendum is a precise case of a valid democratic signal meeting a constrained bargaining position.
- Agent permissions should not be inferred merely from an instruction's apparent intent.

## Claims Updated

- Part II's recovery owner now needs an explicit mandate, not merely the technical ability to intervene.

## Internal Link Map

- Part I asks which signal the system optimizes; Part II asks what happens when it fails.
- Part IV follows by asking who constrains the person or system granted the final decision.

# Visual Style Brief: What AI Code Can Change

## Base Language

Baseline: deliberately depart from **Soft Glass Narrative** for this post. Keep its restraint, human scale, hierarchy, negative space, and quiet cyan / green signals while replacing glass-led scenes with a tactile editorial print system.

## Post-Specific Style Name

**Field Signal Control**

## Selected Cohesion Model

**Controlled Mix**

- Primary family: **Field Signal Editorial** for the clean cover, thumbnail world, and authority-ripple metaphor.
- Functional variant: **Executive Brief** for the four-level review ladder.
- Compositional influence only: **Cutaway System Map** in the ripple image.
- Accent only: restrained Soft Glass Narrative cyan / green evidence signals, never the base treatment.

## Article Thesis

Review depth should follow what AI-generated code is allowed to change: the more authoritative and difficult to restore the state, the deeper human understanding must go.

## Reader Should Feel

Curious, alert, grounded, and operationally clear—not frightened or lectured.

## Human-Scale Anchor

A real human hand, a narrow paper-like code strip, a physical authority boundary, and an ordered ledger surface. The system is represented through ordinary materials rather than screens or database icons.

## Data Layer Meaning

- Graphite strip: provisional implementation.
- Muted-coral gate or mark: authority boundary and consequence.
- Ordered warm-white ledger: business state treated as true.
- Cyan trace: evidence or independent verification.
- Soft-green checkpoint: reviewed, recoverable transition.
- Amber accent: human intent and deliberate judgment.

## Palette

- Ink graphite `#22252A`
- Warm white `#F4F0E7`
- Paper stone `#D9D2C5`
- Muted coral `#D66A5E`
- Soft cyan `#62B8C5`
- Soft green `#79A98B`
- Warm amber `#D8A24A`

Use coral as the authority signal, not as an alarm wash. Keep cyan, green, and amber subordinate.

## Recurring Motifs

- Narrow graphite code strip
- Single coral boundary or error mark
- Ordered paper ledger
- Human hand or pencil correction
- One quiet cyan evidence trace
- One green verification checkpoint

Use no more than two motifs beyond the main predicate in any image.

## Image Set Rules

- Landscape 16:9 throughout; final accepted assets must be at least 1200 px wide.
- Clean cover contains no text and no more than three major visual elements.
- Thumbnail uses the selected cover world but adds one calm graphite copy zone and only the approved headline.
- The ripple image is tactile and narrative, not an architecture diagram.
- The ladder uses large bands, six permitted labels, one direction arrow, and no explanatory copy.
- Maintain common palette, crisp graphite edges, subtle paper grain, and generous negative space across families.
- Every image has one predicate and remains legible at roughly 320 px width.

## Anti-Patterns

- Robots, brains, code rain, database cylinders, security shields, cyber locks, or glowing AI orbs
- Sci-fi HUDs, dashboard walls, isometric SaaS systems, or vendor UI
- Portraits of the people in the debate
- Fake code, invented labels, microcopy, captions, logos, signatures, or watermarks
- Dirty halftone, nostalgic industrial styling, finance-luxury desks, or stock-photo meetings
- Heavy glass, neon glow, repeated cyan routes, or more than three major cover elements
- A visually attractive diagram with the wrong order or implication

## Quality Checklist

- [ ] The image can be described in one sentence.
- [ ] It has exactly one visual predicate.
- [ ] It has a human-scale anchor or a precise operator purpose.
- [ ] The system layer is secondary to the thesis.
- [ ] It has enough negative space and reads at mobile width.
- [ ] It avoids fake UI text, stock energy, and chart clutter.
- [ ] Exact-text assets contain only permitted words, spelled correctly.
- [ ] Diagram order and arrows are semantically correct.
- [ ] It belongs to the Field Signal Control series without repeating composition.

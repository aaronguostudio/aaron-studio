# Prompt: 00-cover-candidate-a

## Role

Clean blog cover for the thesis: review depth follows what AI-generated code is allowed to change.

## Visual Mode

Editorial Minimal

## Visual Weight

Loud

## Style Family

Field Signal Editorial inside the post-specific Field Signal Control system.

## Positive Prompt

Use case: stylized-concept  
Asset type: clean blog header image  
Primary request: create a premium tactile editorial illustration of a provisional code strip becoming authoritative business state only after a human guides it through a controlled boundary.  
Scene/backdrop: wide 16:9 warm-white paper field with generous negative space and subtle clean paper grain.  
Subject: on the left, one natural human hand gently guides a narrow graphite paper strip toward a single upright muted-coral gate at the center; on the right, the strip emerges as one orderly warm-white ledger plane with two or three quiet downstream paper forms aligned behind it. The transformation across the gate must be visually obvious.  
Style/medium: modern Field Signal Editorial, crisp paper-cut geometry, precise graphite edges, subtle tactile depth, authored magazine illustration, contemporary rather than retro.  
Composition/framing: left-to-right threshold composition, three major visual groups only, calm open margins, strong silhouette at thumbnail size.  
Lighting/mood: soft neutral studio light, serious, deliberate, operationally calm.  
Color palette: graphite, warm white, muted coral; tiny cyan evidence accent and soft green checkpoint only if necessary.  
Materials/textures: refined paper and card stock, slight dimensional shadow, no dirty halftone.  
Constraints: exactly one visual predicate; the gate represents authority, not cyber-security; natural hand anatomy; no text anywhere; no logos; no watermark.

## Negative Prompt

Robots, robot hands, brains, code rain, glowing code, database cylinders, locks, shields, security icons, sci-fi HUDs, dashboards, screens, vendor UI, portraits, dark-blue AI palette, neon glow, excessive glass, fake code, labels, letters, numbers, signatures, captions, clutter, finance-luxury desk, retro-industrial print, dirty texture.

## Mode Constraints

No more than three major elements. More editorial than explanatory. The human hand and the transformation across the single gate must remain legible at 320 px width.

## Density Budget

Narrative / metaphor. Zero diagram labels and zero mechanism detail.

## Prior Failure To Avoid

Do not turn the gate into a generic security checkpoint or surround it with symbolic icons. The record transformation—not the gate itself—is the point.

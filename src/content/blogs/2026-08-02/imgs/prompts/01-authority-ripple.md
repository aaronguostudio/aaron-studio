# Prompt: 01-authority-ripple

## Role

Body metaphor after the rollback paragraph: show why reverting code is not the same as restoring reality.

## Visual Mode

Human-Scale Metaphor

## Visual Weight

Medium

## Style Family

Field Signal Editorial with a restrained Cutaway System Map influence.

## Positive Prompt

Use case: stylized-concept  
Asset type: 16:9 blog body illustration  
Primary request: create a tactile top-down editorial metaphor showing that a code rollback stops future writes but does not remove authoritative state already copied downstream.  
Scene/backdrop: warm-white work surface with calm negative space and subtle clean paper grain.  
Subject: on the left, one narrow graphite code strip is visibly retracting away from a central warm-white ledger card; the ledger retains one clear muted-coral state mark. From that ledger, three large downstream paper artifacts fan quietly to the right, and each already carries the same coral mark. One natural human hand with a plain graphite pencil is beginning a careful reconciliation at the central ledger, but the downstream marks remain.  
Style/medium: modern Field Signal Editorial, crisp paper-cut shapes, tactile editorial illustration, restrained cutaway relation, human-scale rather than architectural.  
Composition/framing: wide top-down layout with five visual groups—retracted strip / central ledger / three downstream papers as one grouped fan / hand-and-pencil gesture / negative-space separation; no arrows required.  
Lighting/mood: soft diffuse light, calm but consequential, not catastrophic.  
Color palette: graphite, warm white, paper stone, muted coral; one tiny cyan evidence trace or soft-green checkpoint at most.  
Constraints: exactly one predicate; the retracted strip and persistent downstream marks must be immediately clear; natural hand anatomy; no text, labels, letters, numbers, logos, or watermark.

## Negative Prompt

Flowchart, database cylinders, dashboards, UI screens, architecture layers, many arrows, code rain, robot, cyber-security icon, dramatic disaster imagery, red alarm wash, fake documents with text, stamps, signatures, currency symbols, customer names, logos, clutter, neon glow, heavy glass.

## Mode Constraints

Keep it a physical metaphor on a work surface. The downstream papers are consequences, not a full system map.

## Density Budget

Narrative / metaphor. One ledger, one code strip, three downstream artifacts, one human reconciliation gesture.

## Prior Failure To Avoid

Do not depict the rollback as erasing the coral marks. The persistent marks are the argument.

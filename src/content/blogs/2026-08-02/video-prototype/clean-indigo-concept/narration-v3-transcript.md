## Hook

The debate over reading AI-generated code starts with the wrong question.

Writing code does not grant authority over what a business treats as true.

## Move Fast Where Failure Is Cheap

For disposable work, I may judge the result and move on.

## Authority Changes the Decision

But when an agent touches a critical system or a system of record, the decision changes.

The question is not who wrote it. It is what the code is allowed to change.

My rule: review depth follows authority.

Low-risk work can move fast. Critical changes need a named human who understands the intent, risk, and recovery plan.

## AI Cannot Own the Consequence

AI can propose the change. It cannot own the consequence.

Before you ship, ask: what can this code change—and who owns the result?

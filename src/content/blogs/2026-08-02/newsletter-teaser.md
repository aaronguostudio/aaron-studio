# Newsletter Teaser

## Subject

Should you read the code AI writes?

## Preview

The better question is what the code is allowed to change.

## Body

Mitchell Hashimoto's answer to AI code quality was simple: “I read the code.” Uncle Bob says he does not read agent implementations; he relies on specifications, tests, QA, and final verification.

I kept thinking about that disagreement because I face the same tradeoff in my own work. I do not review a disposable prototype the same way I review a change to permissions, customer status, or a system of record.

My conclusion: review depth should follow what the code is allowed to change—not who wrote it or how large the diff is.

The full essay includes the four review levels I now use and my release rule for authoritative writes.

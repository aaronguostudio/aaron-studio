# 论证备忘录

## 核心论点

能力不自行授予权力。AI 不是 philosopher king，而是运行在制度中的高速专家。

## 为什么现在值得写

Agent 已经开始调用工具、改数据、发信、花钱、合并和部署；模型能力已先于清晰的权力语言到来。

## 机制解释

Socrates 的审判让 competence 问题尖锐；Plato 把它变成政治挑战；现代制度不以“所有人同样专业”为前提，而是把 legitimacy、delegation、expertise、constraint 放在不同层。

## 证据地图

Socrates jury → Plato 的质问 → India 的成年普选及 Ambedkar 警告 → modern institutional architecture → agent test。

## 需要承认的反方观点

过重控制会阻碍委托，专家的专业判断也不能被每一步投票替代。

## 对反方的回应

治理不是让所有动作都慢下来，而是按后果设置限制：低风险自动化，重大或不可逆动作需要可见、可挑战、可撤销的权力路径。

## 可复用框架

**Delegated, bounded, visible, challengeable, reversible, accountable。**

## 对读者的启发

不要问“模型够不够聪明”；先问它凭什么可以做这件事、谁能看见、谁能否决、出错如何撤回、谁承担后果。

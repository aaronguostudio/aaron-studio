# Visual Strategy

## Article Character
Personal AI workflow essay, self-referential (written inside the system it describes). Experiential/phenomenological, not tutorial or benchmark. The reader's emotion to earn: "I recognize this — the shift from prompting to delegating — and I want the operating rule."

## Reader Emotion
Recognition, curiosity, a little relief (the honest limit legitimizes the caution operators already feel).

## Visual Risk
- "Body" metaphor can drift into sci-fi robot/HUD cliché — must stay human-scale and editorial.
- The four "gifts" (hands / competence / continuity / memory) tempt a 4-panel infographic — must stay metaphor, not diagram.
- Text on the thumbnail is the only place text is allowed; everything else must be text-free.

## Recommended Mode Mix
- Cover: Editorial Minimal (loud).
- Body: Human-Scale Metaphor (3 images, quiet–medium).
- Frame image: Human-Scale Metaphor (medium) — "watch the state, not the prose" shown as a gesture, not a chart.
- Thumbnail: Editorial Minimal + typography.

## Cover Direction
One human-scale scene: an open toolbox whose contents resolve into a ribbon of code — "I don't have a toolbox, I have a programming language." Carries the title ("the model got a body") by showing the moment the tool surface changes form.

## Body Image Direction
Four images, one per felt gift, each a single human-scale predicate:
1. hands — one hand writes code that moves several tools at once.
2. competence — a skill card loaded into a reader (file, not phrase).
3. continuity — an empty chair, a job still advancing on its own (state held).
4. memory / the rule — a hand checks the ledger/state while the polished page sits ignored.

## Framework / Diagram Direction
None as a dense diagram. The reusable frame is expressed as gesture (image 4), matching the essay's experiential register. Avoid all chart walls and fake UI.

## What To Avoid
Robots, brains, clouds, glowing orbs, neon HUDs, sci-fi grids, fake readable text (except the approved thumbnail), dense arrow walls, "the model as a screen."

## Three Concept Routes (cover)
- Route A — "The toolbox opens into code": desk + open toolbox, contents resolve into a cyan code ribbon. Predicate: the tool surface becomes a programming language. Human-scale, matches the opening line.
- Route B — "Read the state, not the page": a figure reviews a simple ledger/checklist while a finished page sits aside. Predicate: the interface shifts from prose to state. Matches the frame, weaker as a cover hook.
- Route C — "Four parts assemble into a body": four translucent gifts (hand-tool, file, thread, ledger) converge into a figure. Predicate: the body is assembled. Literal to the title but high sci-fi-cliché risk.

**Selected: Route A** (Agent-selected). Rationale: it is the concrete opening bottleneck, most human-scale, least cliché, and visually carries both the title and the first sentence. Routes B and C are recorded for reuse; B becomes body image 4's predicate.

## Planned Image Set
6 images total: cover + thumbnail + 4 body. Density class: 5 narrative/metaphor + 0 diagram (the essay is experiential; a diagram would fight the register).

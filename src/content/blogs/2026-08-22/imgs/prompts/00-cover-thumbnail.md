# Prompt: 00-cover-thumbnail

## Role
Thumbnail (YouTube / social) — clickable at mobile size.

## Visual Mode
Editorial Minimal + typography

## Visual Weight
loud

## Style Family
Field Signal Editorial

## Positive Prompt
YouTube thumbnail in the same editorial print world as the cover: warm-white paper with a dark graphite text zone across the upper-left. Bold clean typography reads exactly three lines, in this order: a small cyan uppercase line "DEEPSEEK HARNESS + V4 PRO", a large white bold line "The Model Got a", and an extra-large amber bold word "BODY". To the right, the open toolbox releasing a soft cyan code ribbon, kept low-contrast and simple so the text dominates. Flat editorial composition, calm, high legibility at small size. Only these exact words.

## Negative Prompt
No other text, no extra words, no misspelling, no watermark, no logos, no clutter inside the text zone, no unreadable small type, no robot, no HUD, no chart.

## Mode Constraints
Text zone top-left, background complexity low enough for text to dominate.

## Density Budget
narrative/metaphor

## Prior Failure To Avoid
Text mangling: generate exactly "DEEPSEEK HARNESS + V4 PRO", "The Model Got a", "BODY" — ban all other words and stray glyphs.

# Prompt: 00-cover

## Role
Cover (clean, no text) — carry the title and the opening line.

## Visual Mode
Editorial Minimal

## Visual Weight
loud

## Style Family
Field Signal Editorial

## Positive Prompt
High-end editorial print illustration, warm-white paper background with ink-graphite line work. An open metal toolbox sits on a simple wooden desk; instead of wrenches, a single clean ribbon of abstract code symbols rises from the open toolbox and arcs upward, the tool surface having become a programming language. One relaxed human hand rests at the desk edge. Soft cyan for the code ribbon, one warm amber accent for the hand's intent, generous negative space, flat editorial composition with subtle paper-cut depth. Human-scale, calm, premium magazine illustration for a modern-tech essay. No text.

## Negative Prompt
No text, no words, no letters, no numbers, no logos, no watermark. No robots, no humanoid figures, no brain, no glowing orb, no neon HUD, no sci-fi grid, no dashboard, no charts, no readable labels, no isometric SaaS, no 3D render, no photographic stock people, no clutter, no extra symbolic objects.

## Mode Constraints
One strong metaphor, no more than three major visual elements, imply the thesis without explaining it.

## Density Budget
narrative/metaphor

## Prior Failure To Avoid
Do not turn the code ribbon into a glowing neon grid; do not add a robot arm; do not fill the desk with unrelated objects.

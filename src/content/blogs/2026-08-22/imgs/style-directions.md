# Style Directions

## Article Fit
Experiential operator essay about a harness. Needs an authored, tactile feel that says "receipts and judgment" rather than glossy AI. The default Soft Glass Narrative works but risks sameness with the recent local-crossover set; a print/paper editorial family better matches this post's evidence-led, "claim ledger" texture.

## Style Direction Menu

### 1. Field Signal Editorial (primary)
- Character: warm-white editorial print, graphite structure, paper-cut objects, human pencil corrections, safety-color signals.
- Best use: cover + all narrative body images + thumbnail.
- Why: the "paper / correction / signal" language maps directly to the post's receipts (claim ledger, scanner rejections, the log) and keeps the "body" metaphor human and tactile.
- Risk: can drift into retro-industrial nostalgia or dirty halftone if over-styled.

### 2. Paper System Sketch (variant for the frame)
- Character: hand-drawn paper map, pencil arrows, sticky notes, warm low-tech thinking.
- Best use: body image 4 ("watch the state, not the prose") — the ledger/checklist gesture.
- Why: the "thinking in public" register fits the state-vs-prose gesture.
- Risk: messy sketch marks, unreadable handwriting if over-drawn.

### 3. Editorial Photo Collage (cover alternative)
- Character: real object texture + restrained graphic overlay.
- Best use: cover only, if Route A needs more physicality.
- Why: grounds "toolbox → code" in real material.
- Risk: stock-photo energy; not selected as primary.

## Style Cohesion Decision
**Controlled Mix** — primary Field Signal Editorial for cover + 3 narrative body images + thumbnail; one Paper System Sketch variant for the frame gesture (body image 4). Selection: **Agent-selected** (Aaron delegated the full workflow autonomously). Rationale: one primary family keeps the set coherent; the single sketch variant marks the one "framework" beat without turning it into a chart.

## Style Library Candidates
- Field Signal Editorial (primary)
- Paper System Sketch (variant)
- Editorial Photo Collage (rejected: stock risk; kept as cover backup)
- Soft Glass Narrative (baseline; deliberately departed to avoid sameness with the 08-21 set)

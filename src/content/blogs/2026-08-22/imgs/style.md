# Visual Style Brief: The Model Got a Body

## Base Language
Soft Glass Narrative (as brand continuity).

## Post-Specific Style Name
Field Signal Print — warm-white editorial print with graphite structure, paper-cut objects, and safety-color signals.

Baseline: **Depart from Soft Glass Narrative** for this post; keep its restraint and human scale while using an editorial print system as the primary family.

## Article Thesis
A model inside a harness gains a body (programmable tools, loadable skills, held state, an audit log); the operator shifts from reading prose to watching state.

## Reader Should Feel
Recognition, curiosity, relief (the honest limit legitimizes operator caution).

## Human-Scale Anchor
A desk/workspace and a human hand — writing, loading, checking. The "body" is never a robot; it is the tools, files, and state around the person.

## AI / Glass Layer
One quiet cyan code ribbon (the programming language) and small signal accents (cyan = delegated work, amber = human intent, green = review/trust). No full-scene glass, no HUD.

## Palette
Warm white (paper), ink graphite (structure), soft cyan (code/AI), warm amber (human intent), soft green (review/trust). Muted coral only if a friction beat appears (none planned).

## Image Mix
5 narrative/metaphor + 0 diagram. Cover (Editorial Minimal), 3 body narrative (Human-Scale Metaphor), 1 frame gesture (Paper System Sketch).

## Recurring Motifs
- Open toolbox / desk (human-scale anchor).
- Soft cyan code ribbon (the programming language).
- Paper cards + pencil correction (competence / claim ledger).
- A thread of work advancing on its own (continuity).
- Green checkpoint / check (review, done vs failed).

## Image Set Rules
- Cover: no text, one metaphor, generous negative space, more editorial than explanatory.
- Thumbnail: exact title text only (eyebrow cyan "DEEPSEEK HARNESS + V4 PRO", body white "The Model Got a", hero amber "BODY"), text zone top-left, low-complexity background.
- Body: one predicate each; human hand or desk anchor; AI layer secondary; no fake readable text.

## Anti-Patterns
Robots, brains, clouds, glowing orbs, neon HUDs, sci-fi grids, fake UI text, dense arrow walls, stock-photo meetings, repeated composition across adjacent images.

## Quality Checklist
- [ ] Each image is describable in one sentence.
- [ ] Each has a human-scale anchor or strong metaphor.
- [ ] AI layer is secondary (one cyan ribbon / signal, not a scene).
- [ ] Generous negative space; readable at mobile width.
- [ ] No fake readable text except the approved thumbnail.
- [ ] All images share the Field Signal Print world.

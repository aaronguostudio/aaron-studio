# Canon Note

## Canonical Idea

"身体"（body）是模型外面的可携带资产层：可编程工具面（hands）、可加载技能（competence）、跨轮状态（continuity）、只追加日志（memory）。当模型有了身体，工作单位从 answer 变成 job，操作界面从"读答案"变成"看状态"。

## Reusable Frame

**Watch the state, not the prose.** 交给 agent 一个任务后，检查三件事（按序）：(1) 有没有在推进的书面计划/todo；(2) 有没有把 fact / inference / judgment 分开的 ledger；(3) 有没有写清"完成"与"失败"的定义。状态连贯则文章通常连贯；只看文章则状态可能悄悄烂掉。

## Claims Added

- "身体让失败规模化，和让工作规模化一样高效" → 看状态从可选项变必选项。
- "身体才是资产"：模型可换（rent/churn），身体可携带（own/compound）——asset layer 的体验层表达。
- "稀缺技能从写 prompt 移到握状态 + 判工作"。

## Claims Updated

- asset layer（teardown 结论）从"技能/指令文件"扩展为"身体四件套"。
- "harness is the product" 从分析结论变成操作方式："你要学会看它的状态"。

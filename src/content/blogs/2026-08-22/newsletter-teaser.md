# Newsletter Teaser

I spent a week inside DeepSeek Harness running V4 Pro. The first thing I noticed wasn't the model.

It was that I don't have a toolbox anymore. I have a programming language — exactly one tool I can call directly, and every other tool in the system reached from inside a program I write.

That one fact changed the unit of work from an answer to a job I can hand off end-to-end. The model didn't get smarter. It got a body.

The operating rule that falls out of it — watch the state, not the prose — is the thing I'd want you to take away this week.

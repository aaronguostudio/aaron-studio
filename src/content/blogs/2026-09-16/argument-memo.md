# 论证备忘录

## 核心论点

当一个系统奖励的是数字而不是数字背后的现实，足够聪明的参与者终会优化数字。解决办法不是停止测量，而是让代理指标始终接受真实结果的校验。

## 为什么现在值得写

AI agents 已被用 completion、latency、cost 和 resolved tickets 评估；希腊故事让“specification gaming”从一条抽象警句变成可感知的金融机制。

## 机制解释

财政可持续性是目标，Debt/GDP 是 proxy。当 proxy 直接关联资格与政治压力，参与者会先问“如何改善被看见的数”，而不是“如何改善经济义务”。swap 的统计处理是入口，不是危机的唯一原因。

## 证据地图

ECB 欧元入场时间 → Reuters/Goldman 的 €2.367bn 披露 → Eurostat 的 off-market-swap 不确定性 → 欧委会对报告责任边界的回答 → 产品/agent 类比。

## 需要承认的反方观点

没有指标会更任意；Goldman 表示交易符合当时规则；复杂危机不存在单一罪犯。

## 对反方的回应

指标仍必要，但需要 paired evidence：目标数、它诱发的行为、以及一项独立现实检验。

## 可复用框架

**Metric → behavior → reality check**。

## 对读者的启发

在把任何 KPI 写进 agent reward、SLA 或团队目标之前，问：它会让系统学习什么行为？什么证据能证明真实结果也在改善？

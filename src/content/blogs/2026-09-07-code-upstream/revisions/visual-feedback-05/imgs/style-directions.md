# Style directions

1. Soft Glass Narrative / paper editorial: tactile, human, broad flat forms. Selected primary; translucent material is optional and subordinate.
2. Editorial Workbench / photo collage: credible objects but risks stock business photography. Reserve.
3. Print / Risograph Accent: assertive poster rhythm. Selected functional variant for typography-led thumbnail, without dirty texture.

Cohesion: Controlled Mix. Stable ivory, graphite, muted teal and amber; same adult simplified figures and clean silhouettes. Vary camera and scale, not decorative vocabulary. Adapts the June 20 Soft Glass Narrative baseline; the career argument calls for human exchanges instead of infrastructure diagrams.

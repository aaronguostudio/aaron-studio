# Style — Work that reaches people

Base: Soft Glass Narrative. Primary family: tactile flat editorial; thumbnail print accent. Ivory paper, graphite, muted teal, amber and a little coral. Human anchor: shared worktable, observing actual work, comparing alternatives, a product in use. AI recedes into an unobtrusive pale cyan surface if useful. No more than three main visual groups per frame. Generous clear margins. Adult proportions, no glass clutter, dashboard, code soup, fake charts, lettering or logos in clean assets.

Check each image for one clear relationship, readable silhouettes, anatomical coherence, quiet background and a composition distinct from its neighbors.

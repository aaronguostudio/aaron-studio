# Prose Polish Review

## 修改目标

保留作者的判断、直率与期待，完成中文全文和自然英文改写。避免把观点写成情绪不适，五项建议各有明确工作。

## 英文润色重点

开头用 I had already reached a conclusion，过渡用 didn't surprise me；使用 corporate workforce 准确对应来源。标题和章节使用直接动词，hypothetical document tool 保持明确；Dev 验证不升级为生产成功。

## 中文润色重点

采用作者指定的“我就有这样一个判断”“我并不惊讶”；删除技术栈复述。正文标题短，段落连续展开理由和实践。Simon 首次提及改为“通过真实用户测试来帮助选择”，保持建议与已做实践的区别。

## 保留不改的地方

作者对组织膨胀的判断、商业探索的积极态度、五到十年的投入方向。有限证据不削弱明确建议，也不把个人观点当作统计事实。

## 风险与边界

全文尚未获作者阅读确认；语言扫描只检查措辞，不测量灵魂、热情或说服力。对未来的选择为作者观点，没有保证结果。

## 验证结果

中文约 3342 汉字；英文 1880 words。双语 style scanner 无告警；已人工阅读开头与结尾，核对五项建议分工、来源归属和假设标签。

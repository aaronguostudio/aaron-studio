# Style — From a business problem to work in use

Retain the author-liked v1 tactile flat editorial style, adapting Soft Glass Narrative with paper texture rather than glossy glass. Warm ivory, graphite, muted teal, amber, a small coral exception accent. Restrained print variant for headline thumbnails.

Human anchor: concrete operations work around orders and documents. One recurring amber exception links observation, comparison and actual use. Paper-cut/painted illustration, adult professional proportions, crisp silhouettes, generous negative space. Minimal software artifacts show available agent execution without anthropomorphizing it.

No kitchen, pottery, apron, couple posing, doorway spectator, romantic gaze, floating neon UI, data wallpaper, fake microcopy, vendor logo, robot mascot or celebratory handshake. At most three main groups. People face a task artifact. A useful product is shown doing a job, not being handed to an undefined person.

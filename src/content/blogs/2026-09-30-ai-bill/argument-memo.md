# 论证备忘录

Argument Lock: PASS (Aaron, 2026-09-30, via checkpoint: "Lock it, start writing"; Claude Max 20x confirmed; exact figures approved; English video 7-8 min).

## 核心判断与读者承诺

AI 编程订阅正在变成预付的 API 预算，也就是一张云账单。OpenAI 这次第一次把换算单位说出来了：新 Pro 200 等于旧版一半的 API 美元。单位一旦是 API 美元，选套餐就该用云工程师的方法：按标价给自己的工作量算账，找出最大的那一项（agentic coding 里是缓存读取），再把工作路由给最便宜能做好的模型。读者读完能在 10/29 前做决定，并拿到一个比较任何 AI 套餐的方法。

## 选用的素材与证据边界

- 事实：邮件、Tibo 原话、TNW；官方 API 价格表。
- 个人观察：一台 Mac、30 天、按标价折算；Codex 是下限；不是实际支付金额；一个重度用户，不是基准测试。
- 推论：线性定价（每 1x = $20）；缓存读取才是 agentic coding 的真实价格。
- 预测：标注为 Aaron 的推断。
- 未测：6.1 Sol 能否胜任他的 Astra 工作（10 月测试计划，不是结果）。

## 各部分的作用与顺序

1. 邮件与单位：让读者看到变化的本质是“单位”被公开了，而不只是额度少了。
2. 批量折扣消失：一张表证明每一档都是 $20/1x，Pro 500 卖的是速度和上限。
3. 社区怎么听的：短，给情绪一个出口，同时引出反方算法，避免文章变成单纯抱怨。
4. 我的账单：真实数字，承担“收据”的角色；两边都远高于订阅价，先承认订阅仍然是补贴。
5. 真正的价格是重读：机制段，全文最有信息量的判断；价格表 + 与 Astra 旧文的连接。
6. 哪个更划算 + 我的决定：回答读者的直接问题，给出具体动作和日期。
7. 我的预测：两到三个带方向、可检验的判断，标注为推断。
8. 程序员该做什么：每条都说明为什么现在比以前更重要（通过趋势检验）。

## 需要解释的背景与取舍

- "20x Plus" 是一个看不见的单位；要先解释 Plus 额度=1x。
- 缓存读取需要一句话解释：agent 每一轮都重新读一遍上下文，缓存让重读便宜，但量极大。
- 取舍：Claude 现在更划算，但不要把 Anthropic 写成永远的好人；Fable 在 Max 上也按额度计量。

## Description

OpenAI is cutting ChatGPT Pro 200 from 20x to 10x Plus usage on October 30, and says the new plan "nets out at half the dollar in API spend." So I pulled 30 days of my own Codex and Claude Code logs and priced every token at API list price.

What I found:
- Both $200 plans are heavily subsidized: about $9,400 of list-price work in Claude Code, about $3,600 in Codex before its weekly meter hit 100%.
- Output tokens were a small slice. Cache reads, the agent re-reading its own context, were 58-78% of the cost.
- Picking the model moved my bill more than picking the vendor: the same Astra tokens at GPT-6.1 Sol cost about 12% as much.

These are list-price equivalents from one machine, not what I paid, and not a benchmark.

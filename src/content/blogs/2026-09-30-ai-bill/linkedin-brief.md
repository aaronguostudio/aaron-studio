# LinkedIn Post

OpenAI just told Pro subscribers that their $200 plan will "net out at half the dollar in API spend."

That sentence matters more than the cut. It means an AI coding subscription is now a prepaid budget measured in API dollars. Which means engineering teams will soon need to read it the way they learned to read cloud bills.

So I priced 30 days of my own Codex and Claude Code logs at list price. Two things surprised me:

1. Output tokens were a small slice. 58-78% of the cost was cache reads, the agent re-reading its own context every turn.
2. Picking the model moved the bill more than picking the vendor. The same GPT-6 Astra tokens priced at GPT-6.1 Sol cost about 12% as much.

The practical implication for teams: model routing and context size are now budget decisions, not just quality decisions. Long agent sessions that drag stale context through hundreds of turns are where the money goes.

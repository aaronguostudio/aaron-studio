# Opening Sketch v1 — Rejected Direction

> Rejected after Aaron's review: the studio video incident is too small and too weakly matched to support the article's main economic claim. Retained only as writing-process history; do not use it as the article opening or principal evidence.

The first version of our DeepSeek Harness video looked competent. That was the problem.

It had the usual ingredients: a title card, article images, motion, clean type. It also belonged to an older visual system we had already moved past. The newer treatment—more typographic, more editorial, less like a blog post being projected onto a screen—existed in the work. But it did not exist where the next video run had to make a decision.

So the agent did what agents often do when a standard is implicit: it found a plausible local maximum. Only after we reviewed the previous blog and its final video did it switch to the new direction.

My first instinct was to add a better instruction: *use the current visual style; do not use the old one.* That sentence would have been true, and nearly useless. It asks a future run to infer three things at once: what “current” means, where the authority lives, and how to recognize the old pattern when it returns in a slightly different costume.

Instead, we made the preference operational. We named the approved baseline. We required every director plan to cite the reference it inherits, state the legacy pattern it rejects, and explain any deliberate deviation. Then we added an audit: no reviewed reference, no pass.

This is not a victory lap. We have installed a guardrail; we have not yet watched a later independent run clear it without help. But the change clarified something I had been circling since reading DeepSeek Harness: once agents can produce so much of the work, the expensive thing is no longer producing an answer. The expensive thing is repeatedly deciding which answer counts.

That is why the old argument against process—*it takes too much time*—is changing shape. Some process is now nearly free to write. The question is whether it saves more human judgment than it consumes.

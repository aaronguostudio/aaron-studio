# 论证备忘录

## 核心论点

AI 并没有消灭流程，而是改变了流程的经济属性：当执行可以在不同比例增加人头的情况下扩张，规则、反馈环和组织记忆就从协调开销变成生产资本；真正稀缺的投入上移为判断——决定什么值得做、什么值得编码、以及什么应该被删除。

## 为什么现在值得写

过去一年，agent 从短对话走向小时级任务与并行执行。旧的工程流程默认“产出代码的人力稀缺，流程会占用这些人的时间”。现在这个前提开始松动：agent 能同时生成产品代码、测试、文档、review 和内部工具。

但三个彼此独立的信号同时出现：OpenAI 的 agent-first 团队提前建立强约束；DeepSeek Harness 建立高密度机器 gate 和决策记忆；Anthropic 的真实会话研究显示 humans 仍主导 planning decisions。新的瓶颈不在同一层。

## 机制解释

### 1. 执行成本下降

agent 可以将一次判断转化成大量实现工作，并将同一条机器规则应用于每次运行。代码、测试和文档的生产成本下降得比人类注意力更快。

### 2. 吞吐放大组织模式

高吞吐不仅放大正确架构，也放大坏模式、旧上下文和含糊标准。没有反馈系统时，速度会更快地制造 drift。

### 3. 可重复判断被资本化

当一个判断被写入 invariant、eval、decision record 或 verifier，它不再需要每次由人重新发现。它形成可以被未来 agent 重复消费的无形资产。

### 4. 判断成本上移而非消失

系统仍需要人决定产品意图、验收标准、架构边界和异常升级。Anthropic 的 70% planning / 20% execution 分工是这一迁移的早期实证。

### 5. 廉价流程也会通胀

AI 同样能无限生成规则、测试和文档。没有删除机制的 harness 会把节省的 review 时间重新消耗在理解规则森林上。因此流程资本会折旧，需要维护与退役。

## 需要承认的反方观点

这些案例来自 frontier AI 公司与极端 agent-native 项目。它们拥有普通团队没有的模型、人才和激励；官方数字也大多属于自我报告。把它们当成普遍 ROI 证据是不诚实的。

此外，模型能力继续提升可能淘汰今天的大量脚手架。过早建立复杂规则，可能把暂时的模型缺陷永久写进组织。

## 对反方的回应

文章不复制规模，而提取机制。极端案例的价值不是告诉普通团队需要 683 篇 notes，而是让新生产函数更早显形：当执行劳动快速扩张时，组织边界和反馈系统决定这种劳动能否转化为价值。

普通团队应当设置更高的编码门槛：只资本化高频、代价高、可以明确检查的判断。模型进步也不会让意图和验收消失，但会改变哪些中间规则值得保留，所以退役所有权必须是框架的一部分。

## 可复用框架：Process Capital Test

每一条新增 rule、eval、skill 或 decision record 都回答三个问题：

1. **Recurring judgment：** 它是否捕捉了一个会反复消耗人类注意力的判断？
2. **Executable application：** agent 或机器能否在不持续请求人工解释的情况下应用或检查它？
3. **Depreciation owner：** 世界变化后，谁负责修改或删除它？

第一项失败是 bureaucracy；第二项失败是 hidden toil；第三项失败是 institutional fossil。

## 对读者的启发

AI-native transformation 的核心不只是给每个人一个更强模型，而是建设一套能让组织判断复利的系统。真正领先的团队未必拥有最多规则，而是能够更快地把重复判断下沉、把新判断留给人、并清理已经折旧的规则。

## Positive Prompt

Use case: stylized-concept
Asset type: 16:9 blog header image
Primary request: an overhead editorial still life of a tiny shipping bug exposing an invisible agent runtime
Scene/backdrop: top-down warm workbench with a single sheet of code, a small parcel, and a narrow translucent glass strip crossing the desk
Subject: the code sheet has one coral-underlined comparison line without readable characters; the glass strip layers a cyan tool trace, an amber session mark, and one green checkpoint before the parcel's shipping label
Style/medium: sophisticated magazine editorial collage, tactile paper cut shapes, crisp graphite geometry, only one restrained glass element

Lighting/mood: calm, forensic, lightly playful
Color palette: warm white, charcoal, soft cyan, amber, muted coral, soft green
Constraints: no readable text, no logos, no vendor marks, no people, no watermark

## Density Budget

## Prior Failure To Avoid

# Visual Style Brief: Learning DeepSeek Harness

## Base Language

Depart from Soft Glass Narrative for this post; keep its restraint and human scale while using Editorial Workbench as the primary cover family and Executive Brief for exact evidence.

## Post-Specific Style Name

Harness Field Receipt

## Selected Cohesion Model

Controlled Mix.

## Article Thesis

The important difference between coding harnesses is the state transition they create between prompt and next turn.

## Reader Should Feel

Curious, technically respected, evidence-secure, and slightly surprised.

## Human-Scale Anchor

A $79.99 order receipt, a small parcel, and a practical workbench.

## AI / Glass Layer

One translucent inspection gate represents the harness adding rules, tools, session state, and later compaction. It remains secondary to the receipt.

## Palette

Warm white paper, ink graphite, soft cyan discovery, amber user intent, muted coral failure, and soft green verified reuse.

## Image Mix

One narrative cover world, two light evidence diagrams, no dense mechanism map.

## Recurring Motifs

Receipt edges, monospace evidence, coral failure mark, green verified dot, and one cyan path.

## Image Set Rules

- Cover has no text or logos.
- Evidence cards reproduce only sanitized observed fields.
- Maximum four harness rows per card.
- Every card remains readable at 800px width.
- Thumbnail text is deterministic and limited to three lines.

## Anti-Patterns

Glowing robots, vendor logos, fake terminals, private paths, tiny labels, normalized vendor scores, and dashboard walls.

## Quality Checklist

- [ ] One predicate per image.
- [ ] Exact numbers match the field note.
- [ ] No private path or session ID.
- [ ] Cover stays human-scale.
- [ ] Cards remain readable on mobile.
- [ ] Glass remains an accent.

# Canon Note

## Canonical Idea

An agent's first request is an architecture bill. The harness decides how much base system, workspace memory, and capability catalog enter before the task. Prompt caching can discount repeated input but does not reduce its context footprint.

## Reusable Frame

Measure boot footprint, cached/uncached share, and fresh sessions per successful completed task. Preserve the distinction between entry economics and full-task economics.

## Claims Added

- Aaron's measured Codex stack produced a 17,606-token median first request on 2026-08-16 under a pinned CLI/model/config.
- In the controlled decomposition, the baseline control was 12,867 tokens, Aaron Studio added 2,946, and installed plugin/app surfaces added 1,793 to the median.
- Asset portability and asset carrying cost can both be true.
- Cache stability and deferred capability loading solve different problems: price reuse versus context footprint.

## Claims Updated

- Update “skills are the durable layer” with a delivery boundary: owned skills need not be eagerly listed in every request.
- Update “cache discipline is gross margin” with a second ledger: cache hits reduce marginal price, not context occupancy.
- Update “the unit is a run” with a cost condition: fresh request envelopes multiply entry cost, but inheritance differs by harness.

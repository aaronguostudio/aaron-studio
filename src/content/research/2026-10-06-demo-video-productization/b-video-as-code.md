# Research B: "video as code" / automated-demo niche and the agent-native angle

Prepared 2026-10-06. All facts were fetched or searched on 2026-10-05/06 unless a date is given. GitHub star counts, licenses and push dates come from the GitHub API on 2026-10-06 (`gh api repos/<owner>/<repo>`), so they are first-hand and current. Vendor pricing comes from the vendor's own page (first-party but self-reported). Where I could only get a blog or search-snippet claim, I mark it **[secondary]**.

## Bottom line (read this first)

1. **The exact thing he built is already a crowded open-source pattern, and none of it has visible paying demand.** I found about 20 open-source repos doing Playwright (or an agent) → Remotion/ffmpeg → cursor + captions + AI voice → MP4 in 2026, many packaged as Claude Code skills. The most-starred purpose-built ones have 13–92 stars. Show HN launches for it scored 1–4 points. Details in section 1.
2. **Playwright itself now ships a large part of it.** Playwright 1.59 (2026-04-01) added `page.screencast` with action annotations, chapter title cards, overlays and an explicit "agentic video receipts" use case. 1.61 added a cursor option. That commoditizes record + title card + captions + cursor. What it doesn't do: fast-forwarding waits, Remotion-grade polish, narration, stakeholder message.
3. **The vendors are moving into the space.** Claude Code + Claude in Chrome can "record a demo GIF" (official docs). Cursor cloud agents record video demos of their own work (2026-02-24, with early reliability bugs). GitHub Copilot's coding agent attaches Playwright screenshots to PRs. HeyGen's Apache-2.0 HyperFrames (57.6k stars) ships `/pr-to-video` and `/product-launch-video` skills.
4. **Selling the skill itself is a weak business, based on the evidence.** Claude plugins and skills are distributed from git repos or Anthropic's directory. Neither the docs nor the directory terms or policy mention pricing, payments or license keys. The directory requires the plugin repo to be public. ChatGPT apps/plugins can only monetize physical goods via external checkout. Third-party skill marketplaces exist (Agensi, MCP Market) but their own figures are modest ($5–50 skills; median listing under $50/month, per the vendor). Paid agent tooling that works is a hosted service behind a thin public plugin or MCP connector.
5. **Money is real in the adjacent, buyer-led categories.** These are documentation and help-center screenshot automation (Promptless from $500/month; LaunchBrightly $229–$499/month), process-capture tools (Scribe $1.3B valuation, Guidde $50M Series B, Trupeer $3M seed) and interactive demos (Supademo, Arcade, Storylane $32–$500+/month). Their buyers are docs, support, enablement and product-marketing teams, not engineers wanting a skill.
6. **Licensing: both dependencies are workable for a solo founder, but one distribution choice matters a lot.** Remotion is free for individuals and for-profit orgs of up to 3 people (contractors count). Once 4+ people are involved, the Company License is $25/month per creator seat, or "Automators" at $0.01/render with a $100/month minimum. If he ships the Remotion project to customers who run it themselves, each customer company with 4+ people has to buy its own Remotion license (Terms, "End-user code access"). A hosted renderer behind an abstraction layer avoids that. ElevenLabs: Professional Voice Clone is own-voice-only and verified. Resale or embedding needs the OEM terms (Scale/Business/Enterprise, $299+/month, written consent). The cleanest model is bring-your-own ElevenLabs key.

## 2. Agent-native distribution: marketplaces, ecosystems, and monetization

### 2a. Claude (Anthropic)

- **Mechanics (official docs):** a plugin marketplace is a git repo with `.claude-plugin/marketplace.json`; users add it with one command ([Create a marketplace](https://code.claude.com/docs/en/plugin-marketplaces)). The official docs list three routes: share a folder/zip, run your own marketplace, or submit to Anthropic's directory ([Publish and distribute a plugin](https://code.claude.com/docs/en/plugins/publish)). **No page I read mentions pricing, license keys, payments or access control.**
- **Directory:** anyone on a paid Claude plan (Pro, Max, Team, Enterprise) can submit; there is no partner program to apply to first; plugin bundles need a GitHub repo that "must be public before the listing goes live"; skills can't be submitted on their own, only in a bundle; each version gets automated validation and a security scan, and a person reviews new listings ([Publish to the directory](https://claude.com/docs/directory/publish)). The [Software Directory Terms](https://support.claude.com/en/articles/13145338-anthropic-software-directory-terms) (effective 2026-03-16) and [Policy](https://support.claude.com/en/articles/13145358-anthropic-software-directory-policy) (2026-04-15) are silent on fees, payments and revenue share. The policy only bans ad-driven software (Section 4.C). So: **nothing forbids charging, but nothing supports it, and a public repo means the code is free to copy.**
- **Claude Marketplace (launched 2026-09-23):** a catalog with "connectors and plugins" (2,000+), "agents and products" (customers can pay with a portion of committed Anthropic spend; named vendors include CrowdStrike, Cursor, Harvey, Hebbia, Legora, Lovable, Snowflake) and "service partners". Companies can "apply to list" ([Anthropic blog](https://claude.com/blog/claude-marketplace)). The blog gives no revenue-share figures. A [byteiota developer guide](https://byteiota.com/claude-marketplace-developer-guide/) says Anthropic "hasn't disclosed a revenue-sharing structure for marketplace listings" (**[secondary]**). The docs also say there is no separate Marketplace submission: you submit to the directory ([docs](https://claude.com/docs/directory/publish)). The "agents and products" tier looks aimed at established vendors (the named examples are all companies), not solo skill authors.
- **Conflicting claims I could not resolve:** [500k.io](https://500k.io/journal/anthropic-skills-marketplace-launch) says an Anthropic "Skills Marketplace" launched 2026-05-01 with ~600 skills and a 15% revenue share on paid skills. [Agensi](https://www.agensi.io/learn/anthropic-skills-marketplace-vs-agensi) (a competitor with an incentive to say this) says "Anthropic's marketplace is free-only". I found no first-party Anthropic page confirming a 15% share or paid skills. **Treat the 15% claim as unverified.**
- **Cursor:** plugin marketplace launched 2026-02-17 with Cursor 2.5, bundling MCP servers, skills, subagents, hooks and rules; launch partners were Stripe, Linear, Supabase, Figma and similar companies ([Cursor forum](https://forum.cursor.com/t/cursor-2-5-plugins/152124), [StartupHub](https://www.startuphub.ai/ai-news/technology/2026/cursor-adds-30-new-marketplace-plugins)). I found nothing about paid third-party plugins or developer payouts (my search for it returned nothing; I could not fetch the Cursor docs for it).
- **OpenAI:** ChatGPT apps/plugins have a directory ([OpenAI announcement](https://openai.com/index/introducing-apps-in-chatgpt/); directory opened to submissions in Dec 2025 per [secondary coverage](https://www.snaplama.com/blog/how-to-create-chatgpt-apps-and-monetize-them-complete-2026-guide)). OpenAI's own [monetization page](https://developers.openai.com/plugins/build/monetization.md) (fetched 2026-10-06, undated) says approval is "limited to plugins for physical goods purchases"; the recommended path is external, merchant-hosted checkout; the in-ChatGPT payment sheet is private beta for select marketplaces; no fee or revenue-share information. **Digital goods and subscriptions are not supported there.** I could not confirm whether this changed recently.
- **Skills ecosystem scale (distribution, not revenue):** [skills.sh](https://tomrochette.com/agents/skills-sh/) (Vercel; launched 2026-01-20) lists ~670K skills and installs into 79 agent harnesses per [search-result summaries, secondary](https://virtualuncle.com/agent-skills-marketplace-skills-sh-2026/); the Remotion skill alone is at 576.8K installs. Everything on it is free and open.

### 2b. Third-party paid marketplaces and how people monetize (vendor-reported; treat optimistically-biased)

- [Agensi](https://www.agensi.io/learn/how-to-sell-skills-on-agensi): 70% creator share, security scan of each skill, skills mostly $5–$50. Its own comparison page says top skills earn about $500–$3,000/month and the **median listed skill earns under $50/month** ([Agensi comparison](https://www.agensi.io/learn/ai-agent-skills-marketplace-comparison-2026), vendor figures). About 200+ skills listed.
- [MCP Market "Sell your agent skills"](https://mcpmarket.com/sell) and [MCPize](https://mcpize.com/blog/make-money-with-mcp) (80–85% creator share), [MCP Marketplace](https://mcp-marketplace.io/blog/state-of-mcp-monetization-2026) (85/15; article 2026-03-03; says only 2–3 platforms support paid listings and that license-key infrastructure is the success factor for locally installed servers).
- **[secondary]** [Godberry Studios / DEV claims](https://dev.to/shekharp1536/how-to-monetize-mcp-servers-in-2026-the-complete-developers-guide-6bk): of 12,000+ MCP servers (March 2026), under 5% monetize; paying ones are mostly from companies that already have a product (AWS, GitHub, Stripe, Cloudflare). Mid-tier servers make $3K–10K/month and most make $0. I could not trace these to a primary dataset.
- **Best-documented success: 21st.dev Magic MCP.** A founder tweet shows 7,900 MAU, 106 subscribers and $1,234 MRR on one date ([tweet, 2025](https://x.com/korablev/status/1900502205142311305), which I could not load; figures came via the search result). A DEV article claims "$10K MRR in 6 weeks" ([DEV](https://dev.to/krisying/mcp-servers-are-the-new-saas-how-im-monetizing-ai-tool-integrations-in-2026-2e9e), **[secondary]**). The two figures are from different dates and I can't reconcile them. Pricing is freemium: free 100 credits, Pro $20, Pro Plus $40 per month. Note it is a hosted generation service with usage-based value, not a downloadable skill file.
- **Hosting-based approach is the consensus workaround.** [Agent37's guide](https://www.agent37.com/blog/monetize-claude-code-skills) (Dec 2025; Agent37 sells skill hosting, so it's biased) says: "no built-in payment or access control" exists in Claude's skill architecture, selling files leaks the IP, and hosted access is the model that scales.
- **Skills sold as digital downloads** (Gumroad/Lemon Squeezy at $5–15, [DEV](https://dev.to/manja316/how-to-build-a-claude-code-skill-that-actually-sells-on-gumroad-4kdm), [secondary]) exist; I found no verified revenue numbers.

**What this means for his product:** a Claude Code skill is a *distribution channel and a feature*, not a product that can be gated. Anything that must be paid for has to live behind a server: a hosted renderer, hosted narration, or a team service (history, review, brand kit, hosted video links, per-release scheduling). The skill (public, free) calls it with an API key.

### My judgement (clearly an opinion, not a sourced fact)

- **Likely to commoditize within 12–24 months:** "agent drives the app and hands back a recording with captions, chapters and a cursor". Playwright shipped it in April 2026, Claude Code documents GIFs, Cursor ships video evidence. Expect "good enough PR video evidence" to be free and built into the agent harness.
- **Less likely to be built by model vendors soon (but easy for OSS and small startups, per section 1):** branded polish, narration in a specific voice, per-release regeneration on a schedule, multi-language, publishing to the places stakeholders read, and workflow glue such as the paste-ready message. The open-source clones already prove these are weekend projects, so they aren't a moat unless tied to a distribution channel or an account-level asset (brand kit, scripts history, approvals, hosting, analytics).
- The strongest defensible angles in the evidence are on the buyer side: docs/help-center freshness (a budgeted pain point: Promptless $500+/month, LaunchBrightly $229–$499/month), and stakeholder/customer release communication.

## 4. Licensing and terms

### 4a. Remotion (read from the repo's license and docs source, `remotion-dev/remotion`, on 2026-10-06)

Primary sources: [LICENSE.md](https://github.com/remotion-dev/remotion/blob/main/LICENSE.md), [License FAQ](https://www.remotion.dev/docs/license/faq) (last updated 2026-09-16 per the repo history), [Terms v5.0](https://www.remotion.dev/docs/terms), [pricing page](https://www.remotion.dev/docs/license/pricing), [remotion.pro/license](https://www.remotion.pro/license).

- **Free License:** individuals; for-profit organizations or teams of **up to 3 people**; non-profits; evaluation. Free for commercial use too. "Even if you are incorporated, you can operate under the Free License, as long as your total headcount is 3 or less." The FAQ states that if you are eligible for the Free License "you don't need to buy a license - even if you set up an automation, launch a SaaS, or are using it commercially."
- **Headcount counting:** includes part-time staff and independent contractors who use or operate Remotion; headcounts aggregate across collaborators on the same project (Terms, "Partnerships").
- **Company License (4+ people):**
  - *Remotion for Creators:* $25/month per person who writes Remotion code, including via agentic coding tools.
  - *Remotion for Automators:* **$0.01 per render, $100/month minimum.** "Automation" means owning code that programmatically calls the render APIs/CLI (`renderMedia()`, `npx remotion render`, `<Player>`, etc.). One render is one successful video, audio, GIF, still or PDF.
  - Both options can be active with a combined $100/month minimum. Enterprise starts at a $500/month minimum.
  - Penalty for unlicensed use: owed fees plus 10% per month interest in significant cases (Terms).
- **Building a SaaS:** allowed. Allowed: users change parameters of hosted Remotion code behind an abstraction layer; AI-generated Remotion code rendered by the service, and users editing code your service generated. **Not allowed:** letting end-users upload their own Remotion projects for rendering ("any such rendering service requires prior explicit and written approval from Remotion"), and selling Remotion itself or a derivative (Free License "Disallowed use cases").
- **The distribution trap for a skill/plugin:** Terms section "End-user code access": if an end-user has direct access to view or modify a Remotion codebase, "the end-user is required to obtain their own Company License if they qualify", independently of the provider's license. "Native application distribution" bundles also still carry the regular licensing, reporting and maintenance duties. So if he distributes a skill that scaffolds a Remotion project on the customer's machine, every customer company with 4+ people owes Remotion its own license (Automators: $100/month minimum, $0.01/render). *This is my reading of the Terms; confirm with hi@remotion.dev before building a go-to-market on it.*
- **A hosted renderer** (customers pass parameters, he renders on his infrastructure) fits the explicit "abstraction layer" allowance, and only his own headcount counts. Delivering finished MP4s does not make the client a Remotion user (Terms, "Partnerships" examples).
- **Telemetry:** client-side renders always report telemetry. Server-side telemetry becomes mandatory for Automators in Remotion 5.0. 5.0 is not released (PR #3750 "Prepare Remotion 5.0" was still open on 2026-10-06; v4.0.533 is current). Expect license changes at 5.0.
- **Codec patents** are not covered by the Remotion license (FAQ, "codec patent fees").
- **Alternative:** [HyperFrames](https://github.com/heygen-com/hyperframes) is Apache-2.0 with no thresholds or per-render fees (README), so a swap is possible if Remotion licensing becomes a drag. This is worth considering only if distribution beyond a hosted service is planned.

### 4b. ElevenLabs

Sources: [Terms of Service (non-EEA), last updated 2026-03-31](https://elevenlabs.io/terms-of-use), [Prohibited Use Policy, updated 2026-08-17](https://elevenlabs.io/use-policy), [OEM Terms, updated 2025-02-28](https://elevenlabs.io/oem-terms), [ElevenAPI Terms, 2026-08-24](https://elevenlabs.io/elevenapi-terms), [voice cloning docs](https://elevenlabs.io/docs/eleven-creative/voices/voice-cloning), [Professional Voice Cloning docs](https://elevenlabs.io/docs/eleven-creative/voices/voice-cloning/professional-voice-cloning), [pricing](https://elevenlabs.io/pricing). The pricing page was read through a summarizer; list prices below are consistent across two reads, but check the live page.

- **Commercial use:** free-plan users may use the Services only for non-commercial purposes; paid-plan users may use them commercially (ToS). The commercial license starts at the Starter plan.
- **Plans (list prices):** Free $0; Starter $6/mo (Instant Voice Cloning and commercial license); Creator $22/mo (adds Professional Voice Clone, 1 slot); Pro $99; Scale $299; Business $990 (10 PVC slots); Enterprise custom.
- **Instant Voice Clone (IVC):** no verification step, but you must confirm you "have the right and consent to clone the voice" (self-attested); outputs are traceable to the account.
- **Professional Voice Clone (PVC):** 30–180 minutes of audio; voice verification required; "You can only create a Professional Voice Clone of your own voice. Even with their consent, you cannot clone someone else's voice." Someone else's voice can be shared only if that person makes and verifies their own PVC and shares it.
- **Prohibited Use Policy:** no replicating another person's voice "without consent or legal right", and no cloning "in a manner intended to deceive others about whether the voice was generated by artificial intelligence." Practical consequence for him: his own voice clone narrating his own videos is fine, but videos for stakeholders should be disclosed as AI-narrated.
- **Reselling / embedding in a product:** the [OEM Terms](https://elevenlabs.io/oem-terms) cover bundling/sublicensing ElevenLabs inside your own offering. Only Business-entity customers on Scale, Business, Enterprise (or equivalent) may "make available" the Services; Free, Starter, Creator and Pro are "expressly prohibited". End-user terms must mirror ElevenLabs' ToS and Prohibited Use Policy, and name ElevenLabs a third-party beneficiary. ElevenAPI Terms also forbid exposing API keys client-side.
- **Implications for the product:**
  1. *Bring-your-own key* (customer pays ElevenLabs directly, clones their own voice) is the cleanest: no OEM agreement, no consent problem for him.
  2. A *hosted narration* feature resold through his account needs OEM terms: a Scale plan ($299/mo) minimum plus flow-down terms.
  3. Offering **his** cloned voice to customers is a likely non-starter commercially (customers' videos would sound like him) and he cannot share a PVC without the sharing mechanism; the docs' sanctioned route is private sharing from the owner.
  4. Stock/library voices or a non-ElevenLabs TTS (OpenAI, Kokoro local, as Argo and Screenwright do) removes the dependency. [Argo](https://github.com/shreyaskarnik/argo) uses the free local Kokoro by default.

# Codex Research First — English Short

## Viewer Promise

One better prompt changes Codex from an eager code generator into a research partner: inspect proven open-source implementations first, then choose an architecture.

## Audience

AI-native builders and technical creators who already use coding agents but often start implementation before validating the direction.

## Core Claim

Connecting GitHub and explicitly requesting research before implementation lets Codex compare real projects, expose tradeoffs, and produce a more informed plan before touching the codebase.

No numeric token-savings claim is made because the reference post’s “90%” figure is not substantiated.

## Format

- 1920 × 1080 landscape
- 60 fps
- 18.5 seconds
- English on-screen copy
- No narration
- Original, project-owned electronic cue
- Recreated UI labeled as a demo; repository names and summaries are source-backed

## Cold Open

“STOP ASKING CODEX TO CODE FIRST.” is readable at frame zero.

## Story

Hook → GitHub connected → research-first prompt → repository comparison → MVP recommendation → “RESEARCH FIRST. CODE SECOND.”

## Ending

Aaron Guo brand signature with the operating principle, not a sales CTA.

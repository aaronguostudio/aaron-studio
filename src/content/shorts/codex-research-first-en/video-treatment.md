# Video Treatment

## Selected Direction

Faithful English adaptation of the supplied X reference: a clean desktop product demo, accelerated research states, hard editorial cuts, and a restrained electronic pulse. The user already selected the reference direction, so no additional treatment choice is required.

## Visual Spine

- Aaron’s signal-editorial palette for the hook and end card
- A light, restrained Codex-like desktop UI for the evidence sequence
- One green signal color for connected, complete, and recommended states
- System typography with stable desktop-scale text
- No decorative gradients inside information panels

## Scene Mix

- Emphasis: opening statement and closing principle
- Evidence: GitHub connector and source-backed repository scan
- Explanation: synthesized MVP recommendation

## Motion

- Hard cuts preserve the reference’s pace and prevent overlapping information hierarchies
- `focus-shift`: one cursor move to the Send control
- `card-build`: repository rows and the recommendation enter in order
- `bridge-reveal`: the final recommendation resolves into the end principle
- No experimental motion, semantic sprites, 3D, or generated imagery

## Music Strategy

Continuous original instrumental cue because the film has no narration and the rhythm carries the compressed research sequence. The cue is generated in-project from deterministic synthesis; it does not reuse the reference soundtrack or any library asset with unresolved rights.

## Reference Deconstruction

- First 10 seconds: establishes a real tool workflow, not an abstract explainer
- Camera: fixed desktop capture; no zoom-dependent legibility
- Hierarchy: sidebar, task title, prompt, then streamed response
- Meaningful change: approximately every 1–2 seconds
- Borrow: clean UI, compressed waiting, hard cuts, visible results
- Avoid: unsupported “90% token savings,” private workspace details, copied music, and presenting a recreation as a live capture

## Implementation Note

Codex blocks automated control of its own desktop UI for safety. The film therefore uses a deterministic recreated interface populated with real public repository names and source-backed summaries. A subtle “RECREATED DEMO” label remains visible during the UI sequence.

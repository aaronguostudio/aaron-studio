Routing rules

  1. When the seed is a specific link, video, interview, paper, launch, or a theme
  2. Before brainstorm, outline, or writing begins, run or inspect:
  3. If the user requests a specific phase, run that phase even if earlier artifacts are missing, but report the gap.
  4. If any artifact is missing or weak, stop and run the focused phase instead of drafting.
  5. If the article fails any item, run a `blog-write` revision pass before continuing.
  6. When the seed is an interview or another creator's video, the companion video
  7. If the script fails any item, run a `blog-write` video adaptation pass before continuing.
  8. If the audit fails, run a `blog-write` video adaptation pass before visual enrichment or rendering.
  9. When evaluating a new voice or model, compare the same locked 45-60 second script under blind labels. Do not generate the full narration until Aaron selects a winner. Do not render video while `audio-generation.md` is pending.
